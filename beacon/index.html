Engineering notes
  • Nothing missed, nothing doubled. Each run re-scans a 6-hour overlap and skips mail already processed.
  • Sent mail reads differently. What we send is a confirmed action; what a supplier sends is a claim.
  • Attachments are evidence. PDFs, spreadsheets and photos are read; order refs come from file names too.
  • Failures don't block the queue. Retries with backoff; 3 failures and a person takes it.
  • Runs on free tiers. The 240k-code catalogue is split into sorted chunks with a binary-search index.
  • Tested before it ships. Automated suites cover the API, permissions, screens and invoice builder.
