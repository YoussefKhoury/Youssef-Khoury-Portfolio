04 / How it's built

Plain parts, wired so a mistake is cheap to spot and undo.

1 · Source

Outlook mailbox

Microsoft Graph, with read and draft access only. No send.

2 · Agent

Python mail agent

Runs every 15 minutes with attachments, open orders and past lessons.

3 · Model

Language model

One strict JSON object per email. A second call re-checks every order update.

4 · Hub

Cloud API + database

Validates, applies and logs each change with its source email.

Feedback loop: every Fix it, Wrong or undo becomes a lesson the agent reads before its next run. Every Right counts toward autonomy.

Engineering notes
  • Nothing missed, nothing doubled. Each run re-scans a 6-hour overlap and skips mail it has already processed.
  • Sent mail reads differently. What we send is a confirmed action; what a supplier sends is a claim.
  • Attachments are evidence. PDFs, spreadsheets and photos are read, and order references are picked up from file names.
  • Failures don't block the queue. Calls retry with backoff; an email that fails 3 times is set aside for a person.
  • Runs on free tiers. The 240k-code catalogue is split into sorted chunks with a binary-search index.
  • Tested before it ships. Automated suites cover the hub's API, permissions, screens and the invoice builder.

05 / Rules it can't break

Useful only if the team can trust it, so the limits come first.

Most of the design work went into what the agent is not allowed to do.

It can't send email

No send permission. Replies and invoices stay drafts until a person confirms.

It never invents a number

Missing prices, dates and lead times stay blank. A guess is worse than a gap.

Exact codes only

Near matches are shown for review, never filled in.

Money stays private

Priced documents are recognised by name and kept out of shared project files. Costs are admin-only.

Checked twice, traceable always

A second AI call re-checks every order update. Each change is logged and can be undone in one click.

Autonomy is earned

Hub-only actions run alone after five approvals in a row. Replies to clients always wait for me.

07 / How I measure it

Proving it with numbers, not impressions.

  • Accuracy: plans right first time, by action type.
  • Trust: agent changes kept versus undone.
  • Speed: time from a supplier email to a correct order card.
  • Turnaround: time from a request to done.
