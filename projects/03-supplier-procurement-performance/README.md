# Supplier Procurement & Delivery Performance

Portfolio case showing how procurement data can support supplier review, sourcing decisions and corrective action.

## Business question

Which suppliers create the most delivery, cost and quality risk—and where should procurement intervene first?

## Deliverables

- Formula-driven Excel dashboard covering spend, OTIF, fill rate, delay, price variance and defects.
- Supplier scorecard and prioritized performance-exception queue.
- Category-spend view and governed metric dictionary.
- Reusable SQL analysis for supplier and category performance.
- Clean source tables: 300 purchase orders and 20 suppliers.

## Decision use

The scorecard keeps price, delivery and quality separate before combining them into a transparent risk score, supporting fair supplier reviews and targeted corrective actions.
