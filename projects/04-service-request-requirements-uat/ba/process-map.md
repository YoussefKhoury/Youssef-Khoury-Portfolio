# Service Request Process Map

## As-is

Email or message -> manual triage -> inconsistent assignment -> follow-up by memory -> closure without standard evidence -> manual reporting.

## To-be

Validated intake -> priority calculation -> rules-based queue -> accountable owner -> SLA monitoring -> warning and escalation -> evidence-based closure -> governed reporting.

## Control points

1. Mandatory fields and duplicate warning before submission.
2. One accountable queue and request owner.
3. Timestamped reassignment and status history.
4. Approved response and resolution SLA definitions.
5. Controlled pause states and escalation rules.
6. Resolution code, evidence and requester confirmation.
7. Role-based access and immutable audit trail.
