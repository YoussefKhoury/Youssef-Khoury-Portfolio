# Customer Receivables & Collections Command Center

Portfolio case showing how an analyst can turn invoice-level data into a controlled collections workflow.

## Business question

Which customers and invoices create the greatest cash risk, and what should the collections team do first?

## Deliverables

- Formula-driven Excel dashboard with aging, overdue exposure, DSO proxy, promise coverage and action queue.
- Customer risk summary and governed metric dictionary.
- Reusable SQL analysis for aging, customer risk and collection prioritization.
- Clean source tables: 360 invoices and 48 customers.

## Decision use

The command center separates disputes, broken promises and aging risk so collections activity can be prioritized by recoverable cash—not just invoice age.
